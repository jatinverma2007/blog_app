# MERN Blog – Full-Stack Blogging Platform

## Tech Stack:
React, JavaScript, Vite, Redux Toolkit, TailwindCSS, shadcn/ui, Node.js, Express.js, MongoDB, REST APIs, JWT Authentication, Cloudinary, React Router DOM, GitHub

## Description –
Developed MERN Blog, a full-stack blogging platform enabling users to create, publish, and share blog posts with rich text editing and Cloudinary image uploads. Implemented secure JWT authentication with bcrypt encryption, real-time engagement through likes and comments, and a personalized dashboard to track blog performance metrics.

## Features –
User authentication (JWT & bcrypt), blog CRUD operations, rich text editor, publish/unpublish toggle, like & dislike system, commenting system with likes, Cloudinary image uploads, user dashboard with analytics, profile management with social links, dark mode support, responsive design, Redux state management with persistence, and protected routes with authentication middleware
